# CURRENTLY INACTIVE — SSR future work

Everything in this directory belongs to the **paused** SSR reproduction path.
It is not part of the current experiment and is not on any execution path.

## Why it is here

The repository was first built to generate SSR-style bugs: an OpenRouter model
acting as injector and solver, first-order REMOVAL and HISTORY_REVERSION bugs,
second-order failed-solver bugs, and a 30/30/40 sample of 100 generated bugs.

The project has pivoted to auditing **official SWE-smith task instances that
were actually used to train SWE-agent-LM-32B**. No bug generated by the code in
this directory may enter the current review sample.

## What is here

    ssr/          the generation library: action protocol, agent loop,
                  execution backends, validation, deduplication, the SSR
                  sampler, the pool reader
    scripts/      generate_bug, validate_bug, run_solver,
                  build_second_order_bug, deduplicate_bug_pool,
                  select_review_sample, check_environment,
                  compute_patch_metrics
    configs/      generator, solver, validation, environments, and the
                  30/30/40 SSR sampling plan
    prompts/      injector (removal, history reversion) and solver prompts
    tests/        the tests for the above, plus the smoke repository and
                  synthetic pool builders

## State when it was parked

It worked. Generation, validation, solving and second-order construction ran
end to end against a real repository, and the downstream path ran at full
100-bug scale. Nothing here was abandoned because it was broken.

Two things blocked a corpus run at the time: Docker was not installed, and the
configured model was blocked by an OpenRouter account setting. Neither is a
defect in this code.

## Returning to it

The modules import from `ssr.paths`, `ssr.util`, `ssr.config` and
`ssr.taxonomy`, which are still live at the repository root. Moving a file back
should be enough to run it, but re-read `docs/` first: the active
documentation now describes the SWE-smith audit, not this path.
